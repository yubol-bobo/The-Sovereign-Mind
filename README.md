# Cognitive Intelligence

> 把思考留给自己的大脑。

AI 可以替我检索、总结、执行，但不能替我**理解**、**判断**和**感受**。
这个项目只做一件事：安排我怎么读书——用阅读这种最"作弊"的方式，与真正优秀的思想和灵魂对话，在别人的生命里找自己人生的答案。

## 三个选书标准

书单里的每一本，至少满足其中两条：

1. **思想密度** —— 读完之后，看世界多了一个再也摘不掉的镜头（如戈夫曼的"前台/后台"）。
2. **审美密度** —— 句子本身值得慢读、重读、抄下来（如茨威格）。
3. **生命密度** —— 一个真实或虚构的人，把一生摊开给你看（如塔拉·韦斯特弗）。

不收：只有一个观点却写了三百页的畅销书、鸡汤、"X 分钟读懂 Y"。

## 阅读纪律

1. **先读，后问 AI。** 读之前不看摘要、不听拆书。读完、写完自己的笔记之后，才可以把 AI 当辩论对手——让它反驳我，而不是替我总结。
2. **纸质书 + 一支笔。** 手机放在另一个房间。每次至少 45 分钟不中断。
3. **一本书，一页纸。** 读完用自己的话写一页（见模板）。写不出来，就是没读懂。
4. **重读优于多读。** 一年 24 本就够了。真正的好书，第二遍才开始。
5. **允许弃读，但要写下为什么。** "读不下去"也是一种判断力，前提是能说清理由。
6. **轻重搭配。** 手边永远同时放一本"硬书"（上午/整块时间）和一本小说或诗（睡前）。

## 节奏

- 每天：早晨 45–60 分钟硬书，睡前 30 分钟文学。
- 每周：《红楼梦》两回，贯穿全年（120 回 ≈ 52 周）。
- 每月：两本主线书，两页笔记。
- 每季：回看笔记，挑一本重读。
